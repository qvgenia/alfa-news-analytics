# Alfa News Analytics

Персонализированная новостная аналитика
для крупного бизнеса.

## Tech stack

- Python
- FastAPI
- PostgreSQL
- LLM Gateway
- Retrieval-Augmented Generation (RAG)

## Team

- Role A: Client profile and database
- Role B: News ingestion, RAG and ranking
- Role C: LLM Gateway, agent and UI
